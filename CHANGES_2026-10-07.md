# SliderApp feature update — 2026-10-07

## Added pages

### `/watermark`
- Native SliderApp page using the existing dark/indigo/purple theme and navbar.
- Preserves the original Photo GitHub Pages behavior:
  - `XIAOMI 14T` bottom-left.
  - Current `YYYY.MM.DD HH:mm` timestamp bottom-right.
  - Browser-only canvas processing; the selected photo is not uploaded.
  - JPEG export at 0.95 quality.
- Adds drag/drop, preview, filename display, clear action, and responsive layout.
- A standalone GitHub Pages-compatible version is included at `photo-watermark-standalone/index.html`.

### `/chat`
- MongoDB-backed shared chat interface.
- Device-local display name and sender identity.
- Send multiline messages, timestamps, own/other message bubbles, delete own messages.
- Polls every 2 seconds so multiple devices see new messages without adding a websocket dependency.
- Uses MongoDB collection `chat_messages` (created automatically on first write).

Backend routes:
- `GET /chat/messages`
- `POST /chat/messages`
- `DELETE /chat/messages/:id`

### `/expenses`
- Monthly finance tracker for deposits and expenses.
- Month navigation, categories, descriptions, transaction dates, edit/delete.
- Summary cards for deposits, spending, and net balance.
- Expense-category breakdown with percentage bars.
- Currency display preference stored locally (MYR default; USD/SGD/GBP/EUR options).
- Uses MongoDB collection `expense_entries` (created automatically on first write).

Backend routes:
- `GET /expenses?month=YYYY-MM`
- `POST /expenses`
- `PATCH /expenses/:id`
- `DELETE /expenses/:id`

## Navbar
- Reworked into one data-driven component to avoid duplicated desktop/mobile links.
- Added Watermark, Chat, and Expenses.
- Desktop labels collapse to icons at narrower desktop widths; mobile/tablet uses the existing slide-out menu.
- The old external watermark navbar link now points to native `/watermark`.

## Authentication/data
- All new MongoDB API routes use the existing `x-admin-password` convention.
- All three new Next.js pages use the existing `AuthWrapper`.
- No new npm dependencies are required.

## Deployment note
Because `next.config.mjs` uses `output: 'export'` with `next-pwa`, run the normal frontend production build after installing dependencies so the static export/service worker includes the new pages.
